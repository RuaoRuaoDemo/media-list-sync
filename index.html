媒体名单 · 在线同步源

这个目录只托管一份加密名单，供插件定时拉取。

5649 个媒体 AES-GCM 加密

插件内置的同步地址（已写死，用户无需填写）：

https://raw.githubusercontent.com/RuaoRuaoDemo/media-list-sync/main/media-list.enc

media-list.enc —— 密文文件，直接打开看不到任何媒体名。

怎么更新名单
  • 改完 Excel → 运行 node tools/build-enc.js 重新生成 media-list.enc；
  • 运行 python tools/publish-github.py 覆盖上传（token 只从环境变量读）；
  • 所有装了插件的电脑在设定间隔内自动拉到新名单，无需逐台操作；
  • 名单拉回后再用各自本机的设备密钥加密存储，浏览器存储里也是密文。
安全说明（如实）
  • 密文用 AES-GCM；URL 被第三方看到、抓包、误转发时名单都不会明文泄露；
  • 解密密钥内置在扩展代码里，因此能拿到扩展目录的人仍可解出名单——这属于「不明文暴露」， 不是防内部人员的口令级保护；
  • 这里不含任何 GitHub token 或业务凭证。
